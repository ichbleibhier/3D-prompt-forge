What the skill does

        
Four steps, then it stops

        
It writes the prompt. It doesn't build the project; you hand the prompt to whichever coding model you like.

      

      
    
        
  1. Classify the idea
    Toy, scroll website, looping film, game, explainer or Blender scene. If it fits two, it picks the one that sets the file's structure.
    2. 
        
  2. Ask how hot to run it
    One question: Cheapest, Balanced, High or Maximum. Very detailed ideas with organic parts also get asked about Blender.
    3. 
        
  3. Fill the template
    A swappable brand block, numbers on everything that moves, 4–8 named shortcuts to avoid, and a definition of done.
    4. 
        
  4. Hand it over
    The prompt in one copyable block, 2–3 follow-up fixes for what usually goes wrong, and which model suits it.
    5. 
      

    

  


  

    

      

        

          
Quality levels

          
Set the heat

          
More heat means more scope and more checking for the coding model, so it costs more to run. Smiths judge iron by its color; the colors here follow the same scale.

        

        
        
        
CheapestBalancedHighMaximum

        
Some things never get cut, even at Cheapest: exact numbers, frame-exact animation, three.js inlined with no CDN, mouse and touch, reduced motion, and a definition of done.

Prompt types

        
Six templates on the rack

      

      

        
Interactive toy
Something to poke, squish, drag or configure.
plush · jelly · fidget · configurator

        
Scroll website
A landing page where one scroll value drives the 3D.
sections · brand · reverse scroll

        
Looping film
A short, frame-exact animation whose last frame equals its first.
renderAt(t) · beats · seeded

        
Playable game
One tight core loop with controls, a HUD and a restart.
fixed timestep · ?seed=N

        
Explainer animation
Teaches how something works, one idea per beat.
labels · captions · accuracy note

        
Blender scene
A Python-built scene with renders and a .blend file.
bpy · Cycles · clay pass

      

    

  


  

    

      

        
Install

        
Put it in your toolbox

      

      

        

          
Claude app or claude.ai

          
    
            
  1. Download the repository as a ZIP from GitHub.
    2. 
            
  2. Open Settings → Capabilities → Skills and choose Upload skill.
    3. 
            
  3. Pick the ZIP. It shows up as 3d-prompt-forge.
    4. 
          

        

        

          
Claude Code

          
Clone it into your personal skills folder. Claude Code picks it up on the next start.

          
git clone {{CLONE_URL}} ~/.claude/skills/3d-prompt-forge

          
Then ask: “Write me a prompt for a knitted cactus I can squeeze.”
